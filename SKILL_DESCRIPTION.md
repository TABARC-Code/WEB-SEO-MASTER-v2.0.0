# web-seo-master

Expert Claude AI skill for building, auditing, and optimising websites that rank, convert, and retain.

## What It Does

Audit a live website and get scored across 6 dimensions (technical SEO, on-page, local, UX, content, CRO). Build a landing page from scratch with production-ready HTML/CSS. Optimise for Google, YouTube, or conversion. Fix Core Web Vitals. Understand visual hierarchy. Write CTA copy that converts.

Not generic advice. Specific methodology. Real examples. Human-written research from Brian Dean, MrBeast, and working creators — not speculation.

## Why This Exists

Most web optimisation advice is either too generic ("improve your SEO"), too academic (all theory, no execution), or too scattered (SEO here, design there, conversion elsewhere). This skill connects all of it — because a fast page means nothing if it doesn't rank; a beautiful page means nothing if it doesn't convert; a high-converting page means nothing if nobody sees it.

Every page is a system. This treats it like one.

## Real-World Example

Games Haven is a board game café. Website had 54/100 overall score:
- Technical SEO 42/100: deep URL structure, no schema, outdated footer
- On-page 55/100: H1 is brand name (keyword wasted), broken heading hierarchy, typos
- Local SEO 58/100: two addresses listed, no LocalBusiness schema
- UX 50/100: no hero value prop, two competing CTAs, no reviews near booking
- Content 65/100: strong blog, missing author attribution
- CRO 38/100: off-site booking with no trust bridge, no email incentive

Priority fixes (in order):
1. Fix NAP consistency (high impact, low effort)
2. Add LocalBusiness schema (high impact, low effort)
3. Rewrite H1 to benefit-focused keyword (high impact, low effort)
4. Restructure hero (high impact, medium effort)
5. Add review rating near booking button (high impact, low effort)

That's how this skill works: diagnosis, then prioritised action, then continuous improvement.

## Philosophy

**Kaizen** — continuous improvement mindset. Not "one-time fix and you're done." Every output includes the next iteration roadmap.

**Systems thinking** — pages aren't SEO + design + conversion. They're one system. Fix all three together.

**Research over speculation** — backed by Google Search Central, CrUX data, Backlinko methodology, creator intelligence. Not armchair SEO.

**Execution first** — everything is designed for *doing*, not just reading. Worked examples. Prioritised fixes. Code you can use.

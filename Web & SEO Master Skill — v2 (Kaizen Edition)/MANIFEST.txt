## INSTALLATION

### For Claude Web / App Users:
1. Unzip the package
2. In Claude, go to Skills → Add Skill → Upload Files
3. Upload SKILL.md + all reference files (google-seo.md, youtube-seo.md, ux-design.md, cro.md)
4. Name the skill: web-seo-master
5. Save

### For GitHub Deployment:
1. Unzip the package
2. Create a new GitHub repository named `web-seo-master`
3. Copy all files from the package into your repo
4. Push to GitHub
5. Users can then clone and use locally or reference in their own skill setups

## WHAT'S INSIDE (BRIEF)

**SKILL.md** — Instructions for how Claude should behave. Defines workflows for audits, builds, optimisations. Contains layout system, typography scales, technical SEO scaffolds. No AI traces.

**google-seo.md** — Google ranking methodology. Intent matching, E-E-A-T, keyword research, on-page, technical, Core Web Vitals, featured snippets, link building, AI search, local SEO, cannibalism diagnosis, penalties, schema templates.

**youtube-seo.md** — YouTube algorithm and creator framework. MrBeast's 3-metric system, thumbnail science, hook structure, retention tactics, description architecture, KVS method, A/B testing, tools, analytics.

**ux-design.md** — Visual hierarchy, typography systems, colour systems, layout patterns, mobile-first, accessibility (WCAG 2.2 AA), micro-interactions, retention mechanics, anti-patterns, design for SEO, 2026 trends, testing.

**cro.md** — Friction audits, CTAs, trust signals, forms, email sequences, A/B testing, psychology, analytics, venue CRO, e-commerce, SaaS lead gen, benchmarks.
